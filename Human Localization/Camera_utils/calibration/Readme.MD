# Camera Calibration Parameters

This file stores the camera calibration data used for image undistortion.

## Contents

- Image resolution (`640 × 480`)
- Camera intrinsic matrix (`K`)
- Distortion coefficients (`D`)
- Optimized camera matrix (`new_K`)
- Undistortion maps (`map1`, `map2`)

## Purpose

The calibration parameters are used to correct lens distortion before processing camera images.
